# portfolio-Lahcen-2

Site portfolio statique créé avec HTML, CSS et JavaScript.

## Fichiers

- `index.html` — page principale du portfolio
- `styles.css` — styles et mise en page
- `script.js` — interaction du menu et gestion du formulaire

## Comment l’ouvrir

Ouvrez `index.html` dans un navigateur ou servez-le avec un serveur local.

### Exemple avec Python

```bash
python3 -m http.server 8000
```

Puis rendez-vous sur `http://localhost:8000`.

## Déploiement en ligne

Ce projet est prêt pour GitHub Pages grâce au workflow GitHub Actions défini dans `.github/workflows/deploy.yml`.

Une fois les fichiers poussés sur la branche `main`, la page sera publiée automatiquement.

URL attendue : `https://lahcenmze-collab.github.io/portfolio-Lahcen-2/`
